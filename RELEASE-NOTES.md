## Codex Voice Control 0.1.0 Beta 2

## English

**Automatic readback is enabled by default.** When Codex starts working on a spoken request, Codex Voice Control disconnects voice while Codex continues the task. When the answer is ready, the app reconnects in the same chat and asks Codex to read the answer aloud again.

Turn it off in **Settings → Target chat**. Your stop phrase also cancels a pending reconnection. Automatic readback supports the English and Polish Codex desktop interfaces.

The full cycle was verified in a live Codex chat, including audio playback after reconnecting. Download **Codex.Voice.Control.Setup.exe** for Windows x64.

## Polski

**Automatyczny odczyt jest domyślnie włączony.** Gdy Codex zaczyna pracować nad poleceniem głosowym, Codex Voice Control rozłącza głos, a Codex pracuje dalej. Kiedy odpowiedź jest gotowa, aplikacja wznawia głos w tym samym czacie i prosi Codexa o ponowne przeczytanie odpowiedzi na głos.

Opcję wyłączysz w **Ustawienia → Czat docelowy**. Fraza kończąca anuluje również oczekujące ponowne połączenie. Automatyczny odczyt obsługuje angielski i polski interfejs desktopowego Codexa.

Pełny cykl sprawdziliśmy w rzeczywistym czacie, wraz z odtworzeniem dźwięku po ponownym połączeniu. Pobierz **Codex.Voice.Control.Setup.exe** dla Windows x64.

## Codex Voice Control 0.1.0 Beta 1

An independent Windows x64 companion for opening and closing Codex voice chats with spoken commands. It helps you manage your Codex usage allowance by making it easy to close voice between conversations.

- Choose your start and stop phrases, recognition language and target chat.
- See voice activity in a click-through waveform and customize the sound cues.
- Install offline with the bundled local speech model. The installer adds a desktop shortcut and starts the panel at sign-in.

See the [English guide](https://github.com/AlphaStudioDE/codex-voice-control/blob/main/README.md), [polską instrukcję](https://github.com/AlphaStudioDE/codex-voice-control/blob/main/README.pl.md) and [third-party notices](https://github.com/AlphaStudioDE/codex-voice-control/blob/main/THIRD_PARTY_NOTICES.md).
